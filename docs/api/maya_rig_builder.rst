Maya Rig Builder
================

Runs inside Maya or ``mayapy`` and builds joints, a skin cluster and a
one-shape-per-frame animation from the compressor's output on the selected
mesh. Requires only numpy inside Maya. See
:doc:`../user_guide/maya_rig_workflow`, section 4.
