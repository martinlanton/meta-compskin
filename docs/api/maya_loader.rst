Maya OBJ Loader
===============

Loads OBJ geometry through Maya's importer, either directly (inside Maya) or by
spawning ``mayapy`` from a regular Python session. Used by
:meth:`~metacompskin.model_data.MayaBlendshapeModelData.from_obj_files`.
